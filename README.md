# 视频去水印应用

一个功能完整的视频去水印网页应用，支持视频上传、水印区域标记、视频处理和结果下载。

## 功能特点

- 📁 支持多种视频格式上传（MP4、MOV、AVI、MKV）
- 🎯 手动标记水印区域或使用AI智能检测
- ⚡ 高效视频处理，保持原始画质
- 📱 响应式设计，适配各种设备
- 🎨 现代化UI界面，操作简单直观

## 技术栈

- **前端**：HTML5, CSS3, JavaScript
- **后端**：Node.js, Express
- **视频处理**：FFmpeg

## 快速开始

### 前提条件

- Node.js 14 或更高版本
- npm 或 yarn
- FFmpeg

### 安装和运行

1. 克隆或下载项目到本地

2. 启动应用
   ```bash
   cd video-watermark-remover
   ./start.sh
   ```

3. 在浏览器中打开 `index.html` 文件

## 使用说明

1. **上传视频**：点击上传区域或拖拽视频文件到应用中
2. **标记水印**：
   - 手动标记：在视频预览中拖动鼠标框选水印区域
   - AI检测：点击"AI智能检测"按钮自动识别水印位置
3. **开始处理**：点击"开始去水印"按钮
4. **预览和下载**：处理完成后可预览结果并下载无水印视频

## 注意事项

- 最大支持100MB的视频文件
- 处理时间取决于视频长度和大小
- 请确保已安装FFmpeg，否则无法处理视频
